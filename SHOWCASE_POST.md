# Exploded Niva Concept — interactive Three.js exploded view

Hi everyone! I would like to share **Exploded Niva Concept**, a scroll-driven interactive vehicle showcase built with Three.js and React Three Fiber.

The experience turns scrolling into a camera path through an exploded-view sequence. Visitors can orbit the model, activate an X-ray view, and select body parts to change their colour and material properties.

### Built with

- Three.js + React Three Fiber
- glTF assets and HDR image-based lighting
- custom shader materials for the portal, scan cone and engine accent
- direct mesh picking and runtime material updates
- adaptive device pixel ratio, preloading and shader warm-up
